## [1.0.0] - 2026-05-28

### Added
- Dynamic Load Redistribution Module (DLRM) with direct stiffness method
- Long-Span Stability Assessment Module (LSSAM) with Euler-Riks buckling analysis
- Fatigue Accumulation and Reliability Module (FARM) with Palmgren-Miner rule
- AI-Assisted Support Layer (AISL) with XGBoost anomaly detection
- Long-Span Structural Integrity Index (LSII) composite metric
- Four-level governance decision logic (Steady/Monitoring/Mitigation/Critical)
- Real-time monitoring dashboard with Streamlit
- Continuous sensor data integration pipeline
- Progressive collapse assessment with alternate load path method
- Cornell-Hasofer-Lind reliability index (β) computation
- Rainflow cycle counting for variable amplitude fatigue
- ISO 9224 corrosion degradation modeling
- Complete documentation and API reference
- Full test suite with 8 model validation tests
- Hot-spot stress analysis per IIW recommendations
- Geometric nonlinearity with P-delta effects
- SHA-256 tamper-evidence archival layer
- Physics-constrained AI outputs with bounded uncertainty
